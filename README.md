## Featured Projects

### [JDK Launcher](https://github.com/aselixcore/JDKLauncher)
> Run any JDK instantly — without touching your system environment.

A JavaFX desktop utility for Windows that detects installed JDKs (8+ vendors) and launches fully isolated terminal sessions with per-session JAVA_HOME and PATH.

- No global configuration changes — every session is self-contained  
- Supports PowerShell, CMD, Git Bash, WSL, and Windows Terminal  
- Maven & Gradle integration, custom env vars, theming, system tray  
- Portable release: unzip and run, no install or admin rights required  

**[→ Download v1.0.1](https://github.com/aselixcore/JDKLauncher/releases)**

### [ARM Online](https://github.com/aselixcore/ARMOnline)
> Full browser music player — built from scratch, no dependencies.

Includes 3D coverflow, dynamic theming via Canvas API, and a custom audio engine mirroring the HTMLAudioElement API — enabling a fully functional UI without real audio files.
