## Featured Projects

### [JDK Launcher](https://github.com/aselixcore/JDKLauncher)
> Run any JDK instantly — without touching your system environment.

A cross-platform JavaFX desktop utility for **Windows and Linux** that detects installed JDKs (8+ vendors) and launches fully isolated terminal sessions with per-session JAVA_HOME and PATH.

- No global configuration changes — every session is self-contained
- Windows: PowerShell, CMD, Git Bash, WSL, and Windows Terminal
- Linux: auto-detects your terminal (gnome-terminal, konsole, xterm, and more)
- Maven & Gradle integration, custom env vars, theming, system tray
- Portable on both platforms: no install, no admin/root rights required
